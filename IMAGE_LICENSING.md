## Why this is tracked here, not assumed

A fully public "type anything, get a rendered video with real illustrations"
API run under your own name and billed to your own account needs the same
diligence already applied to Golpo's terms before this project started, and
to Heroicons before Phase 3 shipped. This file exists so that diligence has
a checked-in home instead of living only in a conversation.
